# GUI Tech Stack

**Status:** Canonical / Binding

## Canonical Framework

| Layer | Tool | Binding rule |
|---|---|---|
| App container | Tauri 2 | Desktop shell for Mac-first MVP. |
| Frontend | React 19 | Functional components only. |
| Language | TypeScript | Strict mode. |
| Bundler | Vite | No Webpack. |
| Styling | Tailwind CSS | Semantic tokens only. |
| Components | shadcn/ui | Raw components copied into app. |
| Icons | `lucide-react` | Use icon buttons where appropriate. |
| Generated types | `ts-rs` | Exclusive Rust-to-TypeScript bridge. |
| Async | TanStack Query | Standard query/mutation path. |
| Shell state | Zustand | Shell/navigation state only. |
| Forms | React Hook Form + Zod | Input/review forms. |
| Test runner | Vitest | Presenter and component tests. |
| DOM tests | React Testing Library | View render checks only. |
| Lint/format | Biome | Exclusive JS/TS lint and format. |

## Paths

Expected scaffold:

```text
apps/desktop/
  src/
    app/
    components/
    lib/
    surfaces/
    types/generated/
  src-tauri/
```

Generated raw contracts live only in:

```text
apps/desktop/src/types/generated/
```

## Bans

Do not introduce without explicit founder approval:

- React Router
- TanStack Router
- Redux
- MobX
- Jest
- Cypress
- Webpack
- styled-components
- CSS-in-JS
- custom CSS files outside the global theme
- hand-written TypeScript mirrors of Rust payloads

## Routing

Use Zustand shell state:

```text
activeSurface -> switch -> mounted surface view
```

No URL router for MVP desktop shell.

## Async Rule

Controllers use TanStack Query and shared app helpers.

Do not hand-roll:

- `useEffect` fetch loops
- custom retry systems
- ad hoc Tauri invoke calls inside views

## Definition of Done

Any generated `package.json`, import, component, or path that deviates from this
stack is structurally invalid until corrected.
