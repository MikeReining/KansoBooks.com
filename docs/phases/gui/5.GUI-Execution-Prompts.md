# GUI Execution Prompts

**Status:** Canonical / Operational Prompt Pack

## Purpose

Use these phases to build KansoBooks GUI in bounded AI-assisted slices.

Do not issue one giant prompt such as "build the app." Run one phase at a time.

## Prompt Shape

Every execution prompt must include:

- objective
- required docs to read
- allowed files/folders
- tasks
- non-goals
- verification

## Phase 1 - Desktop Factory Spine

Objective: scaffold the desktop app foundation.

Read first:

- `Docs/TechStack.md`
- `Docs/gui/0.Tech-Stack.md`
- `Docs/gui/0.1.Design-System.md`
- `Docs/gui/1.Invariants.md`
- `Docs/gui/2.Surface-Architecture.md`
- `Docs/gui/4.Enforcement-and-Test-Wall.md`

Allowed to change:

- `apps/desktop/**`
- `scripts/**`
- root workspace/package files

Tasks:

- create Tauri + React + TypeScript + Vite app
- install locked GUI tooling
- configure Tailwind/shadcn foundation
- add institutional white tokens
- configure Biome/Vitest
- create shell state with Zustand
- create placeholder surfaces
- include a placeholder for Policy Setup

Non-goals:

- no product logic
- no import/matching code
- no dark mode

Verification:

- typecheck
- lint
- test
- app launches with white shell

## Phase 2 - Generated Contract Bridge

Objective: wire Rust-to-TypeScript raw contracts.

Read first:

- `Docs/1.Invariants.md`
- `Docs/2.Schema-Design.md`
- `Docs/3.Contract-Type-System.md`
- `Docs/gui/2.Surface-Architecture.md`

Allowed to change:

- `crates/kanso_contracts/**`
- `apps/desktop/src/types/generated/**`
- generation scripts
- workspace config

Tasks:

- add minimal Rust contract crate
- generate TS bindings into `apps/desktop/src/types/generated/`

- prove frontend consumes generated type

Non-goals:

- no handwritten TS mirrors

Verification:

- generation command passes
- stale check passes
- typecheck passes

## Phase 3 - Surface Scaffold Script

Objective: create repeatable surface factory.

Read first:

- `Docs/gui/2.Surface-Architecture.md`
- `Docs/gui/3.Presenter-State-and-Surface-Briefs.md`
- `Docs/gui/4.Enforcement-and-Test-Wall.md`

Allowed to change:

- `scripts/**`
- `apps/desktop/src/surfaces/**`
- package scripts

Tasks:

- create scaffold script for `apps/desktop/src/surfaces/<name>/`
- generate `brief.md`, `state.ts`, `gateway.ts`, `presenter.ts`,
  `controller.ts`, `view.tsx`, `fixtures.ts`, `index.ts`,
  `presenter.test.ts`, `view.test.tsx`
- include presenter comment: "All taste rules MUST be traceable to brief.md."

Non-goals:

- do not build real surfaces

Verification:

- scaffold dummy surface
- run typecheck/lint/tests
- remove dummy if not needed

## Phase 4 - Intake Surface

## Phase 4.5 - Policy Setup Surface

Objective: choose evidence rigor before processing/review.

Read first:

- `Docs/EvidencePolicy.md`
- `Docs/MVP.md`
- `Docs/gui/*.md`

Allowed to change:

- `apps/desktop/src/surfaces/policy-setup/**`
- shell integration files

Tasks:

- expose Lean, Standard, Strict presets
- expose the single override: require receipts for all expenses
- show concise non-advice language

Non-goals:

- no tax advice copy

- render tests cover preset selection and override

## Phase 5 - Processing Surface

Objective: show import progress and safe failure states.

Tasks:

- brief first
- state/presenter/fixtures/tests
- display import batch progress, accepted/quarantined files, fatal findings
- make failures actionable without implying data loss

Non-goals:

- no review actions
- no export

## Phase 6 - Review Workbench

Objective: issue-first transaction review.

Tasks:

- brief first
- group by needs review, suspicious, duplicates, matched
- separate "no evidence found" from "evidence required by policy"
- show match reasons and confidence factors
- show policy reasons and active policy
- expose actions: confirm, reject, choose evidence, mark missing, defer
- expose action: mark statement as sufficient under policy
- preserve `empty` vs `filtered_empty`

Non-goals:

- no ledger/category UI
- no hidden auto-resolution

## Phase 7 - Evidence Drawer

Objective: inspect source evidence and lineage.

Tasks:

- show receipt/document preview or extracted text
- show field lineage
- show match factors
- show audit context

Non-goals:

- no editing source evidence in place

## Phase 8 - Export Surface

Objective: generate clean CSV/report from reviewed state.

Tasks:

- show export readiness
- block export on fatal findings
- represent unresolved review items honestly
- trigger export through gateway/controller

Non-goals:

- no accountant portal
- no direct QuickBooks integration

## Phase 9 - Cutover and Polish

Objective: founder-demo-ready MVP GUI.

Tasks:

- remove placeholder surfaces
- run manual GUI smoke
- verify white design across all states
- fix text overflow and layout shifts

Non-goals:

- no new product scope

## Invalid Prompts

Do not use:

- "Build the full app."
- "Make it premium."
- "Add a dashboard."
- "Implement bookkeeping."

Use bounded phases with allowed files and verification instead.
