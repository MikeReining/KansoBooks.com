# Image Prompt

Style guide: `docs/content-engine/ContentImageStyleGuide.md`

## Accepted Prompt

Create a premium editorial image for KansoBooks, a local-first bookkeeping
product.

Article job: help a small business owner compare local-first bookkeeping files
with cloud accounting systems.

Subject: local-first ownership and accountant handoff.

Scene: a clean white desk with a muted blue local folder, generic exported file
sheets, an evidence checklist sheet, and a sealed accountant handoff packet. Use
only abstract document lines, simple check marks, file icons, and non-readable
microtext. The only readable word allowed is KansoBooks on a small folder label.

Composition: article hero image, landscape 16:9, top-down editorial still life,
clean and spacious, one clear subject cluster, useful rather than decorative,
publication-quality.

Mood: calm, precise, accountant-trustworthy, operator-focused.

Palette: white, near-white, graphite, muted Kanso blue, with subtle green or
amber only for meaningful proof/status marks.

Data safety: no readable financial data, no readable document text, no personal
data, no real bank names, no vendor names, no fake customer names, no fake
totals, no payroll or tax form language.

Local-first boundary: no cloud storage imagery, no server racks, no network sync
metaphors, no hosted-dashboard implication.

Style exclusions: no generic stock photography, no handshake image, no cartoon
style, no glowing AI effects, no fake dashboards, no busy financial charts, no
gradient-orb decoration.

## Rejected Prompt

The first generated prompt allowed too much readable pseudo-document text and
implied accounting categories. It was rejected before project use.
